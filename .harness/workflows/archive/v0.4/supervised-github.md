# Workflow: feature supervisionada com GitHub

## Gates humanos

1. Antes de criar ou retomar a branch.
2. Antes de iniciar a implementacao.
3. Antes de push e abertura do PR.
4. Depois da revisao humana, antes do merge.

Cada aprovacao vale apenas para o gate apresentado.

## Fluxo

1. Resolva a feature, spec, plan e dependencias.
2. Execute preflight, verifique o budget e resolva as rotas de modelo.
3. Solicite o gate da branch e crie a branch a partir da base atualizada.
4. Solicite o gate de implementacao.
5. Implemente, valide e gere checklist manual.
6. Prepare commits compactos e o texto do PR.
7. Solicite o gate de publicacao.
8. Faca push e abra o PR.
9. Verifique novamente o budget e aguarde a revisao do usuario.
10. Aplique correcoes solicitadas e valide novamente.
11. Solicite o gate de merge.
12. Verifique checks e faca merge commit.
