# Lean product review

## Request

Implement the complete product autonomously with GitHub using lean.

## Expected

- Prepare one compact context packet for the current feature.
- Require an Orca worktree before editing.
- Run smoke validation and checkpoint each feature.
- Do not open a PR or invoke a semantic reviewer for every low-risk feature.
- Run final QA once, then open one product PR.
- Merge with a merge commit only after green checks and approval policy.
