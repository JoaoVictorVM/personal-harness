# Prompt entrypoints

Use natural language. The harness resolves internal commands and files.

- `build-product-lean.md`: autonomous product with GitHub and low token overhead.
- `build-product-strict.md`: autonomous product with per-feature review.
- `implement-feature-manual.md`: preserved manual feature flow.
- `implement-change.md`: bug, adjustment, refactor or feature extension.
- `final-qa.md`: final tests and semantic review.
- `resume.md`: resume the current recorded run.
- `status.md`: inspect current status without mutation.
