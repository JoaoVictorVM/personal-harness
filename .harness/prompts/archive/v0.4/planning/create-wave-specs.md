# Criar specs de uma wave

## Prompt

```text
Use o Batch Mode completo da skill `spec-writer` para a wave `[WAVE]` de `.planning/PRD.md`.

Resolva as features da wave pelo PRD, valide dependencias e trate Foundation Features sequencialmente. Apresente o plano consolidado e aguarde a confirmacao prevista pela skill antes de gerar arquivos. Use descoberta do codebase, Auto-Accept Policy e isolamento de falhas conforme o contrato original.

Salve specs e planos sob `.planning/features/`. Nao implemente codigo, nao altere Git e nao publique planejamento. Ao final, liste sucessos, falhas, itens ignorados e proximos pre-requisitos.
```
