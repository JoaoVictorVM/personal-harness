# Criar spec de uma feature

## Prompt

```text
Use integralmente a skill `spec-writer` para gerar a spec e o plano da feature `[FEATURE]` descrita em `.planning/PRD.md`.

Esta e uma execucao manual. Preserve a entrevista, a descoberta de padroes do codebase, as validacoes e todos os artefatos exigidos pela skill. Salve os arquivos sob `.planning/features/`.

Nao implemente codigo, nao altere Git e nao publique os documentos de planejamento. Ao finalizar, apresente caminhos gerados, decisoes, riscos, dependencias e pontos ainda abertos.
```
